# GitTracker Brand Identity & Design System Rules

All agent actions, UI modifications, page generation, styling, and copywriting in this repository MUST strictly follow the GitTracker System Spec 2.0 brand identity and guidelines (`skills/brand-identity`).

## Core Visual Identity
- **Brand Accent:** High-visibility Lime Green `#BFF549` (`rgb(191, 245, 73)`).
- **Dark Theme (Hero / Marketing / Command Center):** Pure near-black `#04060F`, card background `#0F1117`, card border `1px solid #1F2937`.
- **Light Theme (Content / Dashboard interior):** `#F5F5F7`, card background `#FFFFFF`, card border `1px solid #E5E7EB`.
- **Active Card Border:** `2px solid #BFF549`.
- **Logo Mark:** Geometric concentric G mark representing commit topology and version branches converging at the repository core. No drop shadows, no gradient noise.
- **Typography:**
  - Headings: `Inter` (Font weight 900 / Black for hero, 700 / Bold for H1/H2).
  - Body: `Inter` (Regular 400 / Medium 500).
  - Monospace: `JetBrains Mono` / `Fira Code` for code snippets, metrics, scores, formulas.
  - Section Overlines: `UPPERCASE`, letter-spaced (`tracking-widest`), small size, lime green `#BFF549` (e.g., `PLATFORM OVERVIEW`, `SECURITY & FORENSICS`, `COMMERCIAL TIERS`).

## Prohibited Patterns
- Never use muddy multi-colored neon gradients (e.g. purple/pink/cyan mashups) or heavy illustrative clutter.
- Never add drop shadows to cards; use clean structural borders instead.
- Never use exclamation marks in standard interface copy.
- Never substitute `#BFF549` with arbitrary neon greens or yellows.

## Domain Terminology
- **Anti-Cheat:** Always refer to **Codequiry** (or Codequiry Anti-Cheat engine).
- **Ranking System:** Always refer to the **5-Factor Vector Score** (`PAS`, `OCS`, `PIS`, `CIS`, `SDS`).
- **Data Collection:** Use **Telemetry**.
- **Transparency:** The **Zero Obscurity Engine**.
- **Tiers:** Bronze (`#C87941`), Silver (`#9CA3AF`), Gold (`#F59E0B`), Platinum (`#CBD5E1`), Elite (`#BFF549`).
