# GitTracker Brand Identity & Guidelines Rule

Whenever creating, editing, or styling pages, components, or copy in GitTracker, strictly enforce:
1. Primary Accent: Lime Green `#BFF549` (never substitute with random colors).
2. Background: `#04060F` (Dark) or `#F5F5F7` (Light). Card backgrounds `#0F1117` with border `1px solid #1F2937` (Dark) or `#FFFFFF` with border `1px solid #E5E7EB` (Light).
3. Active Card: `border-2 border-[#BFF549]`.
4. Overlines: Section overlines must be ALL CAPS, letter-spaced, text-[#BFF549].
5. Typography: Inter for headings and body, JetBrains Mono for code and metrics.
6. Copywriting: No exclamation points in UI copy. Exact terms: "Codequiry", "5-Factor Vector Score", "Telemetry", "Zero Obscurity Engine".
7. Logo: Geometric Concentric G symbol in Lime Green on Pure Black.
